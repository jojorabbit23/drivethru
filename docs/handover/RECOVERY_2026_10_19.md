# Combined game recovery

## Cause and provenance

The working copies diverged. GitHub main through b6d325f contains newer cooking,
prep/recipe, purchased pump-shotgun, Lancer and vehicle work. Our knife-hands branch
contains the owner kitchen/serving textures, custom pistol, Crop Duster, title videos
and presentation work. D:/zombys/newest/drivethru-main and the_drive_thru match the
shared gameplay scripts; their pistol is the invisible hitscan placeholder. The
drivethru-main project configuration also targets Forward Plus / Godot 4.7 instead
of the project's tested Godot 4.3 Compatibility setup.

OpenCode's newer pistol and movement work was found separately in
C:/Users/rollv/Documents/Default Project. The owner identified pistol commits
1f13dc3 and d5a415e. Their pistol builder, generated hand meshes and gameplay script
were brought across from that copy. Other cooking scripts there match shared main.

## Final integration

- Merge shared main into the presentation branch; retain kitchen_room.gd and
  serving_room.gd builder delegates. Rebuild shop geometry/materials using build_shop.
- Keep the original textured pistol model with OpenCode's new sculpted hands and
  wrist/socket fit, as the owner's final request. Both source models share part
  names and coordinates: replace stock geometry in the animated pistol nodes in
  build_pistol.gd, retaining fire/reload clips. Keep a complete magazine body.

  scene. Draw/cooldown/death/holster gates and finite ammunition are checked.
- Keep the original four weapons, append purchased pump as slot 5 (wheel selects
  any slot). Shop/HUD handle both ammo signal signatures. Preserve both shotguns.
- Preserve OpenCode movement/camera feel, menu/intro/bus, pause/settings/audio,
  original stronger sawn-off, room art, new cooking/prep/holding/order stations,
  Lancer and vehicles. Cosmetic grinder/bin still await gameplay transaction wiring.
- Keep local pump hand fit from be6f6f1: native PSX Firearms pump hands, teal gloves,
  charcoal cuffs, orange sleeves, corrected grip/loading clearance and shared depth.

## Preventing recurrence

Use outputs/drivethru_knife/project.godot and outputs/Play_DriveThru.cmd for this
combined playtest. D:/zombys/newest and Default Project are separate older/divergent
working copies; opening them does not load this integration. No changes were pushed
or written over those copies. Merge/pull shared changes; do not copy entire older
player/main/shop-decor files over this project. Room and pistol resources are generated:
edit their builders and rebuild, never replace generated files alone.
